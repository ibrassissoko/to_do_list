# To-Do List

Une application web simple pour gérer une liste de tâches au quotidien.

## Fonctionnalités
- Ajout, validation et suppression de tâches.
- Filtre par statut (toutes, actives, terminées).
- Sauvegarde automatique dans le navigateur via `localStorage`.

## Démarrage rapide
1. Ouvrez `index.html` dans votre navigateur.
2. Ajoutez vos tâches et gérez-les directement.

## Structure
- `index.html` : structure de la page.
- `styles.css` : styles de l'interface.
- `app.js` : logique applicative.
